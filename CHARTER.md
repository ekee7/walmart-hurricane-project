# Charter

### Goals
Overall result: A final, consolidated notebook that runs from start to finish without any compilation errors that Walmart can use to stock up the store before the hurricane comes to maximize profits.

How we will get there:
Set up repository

Profile the data

Fully clean the data for...
- Duplicate records
- Missing values
- Dates/times in different formats
- The same product under several SKUs and names
- Inconsistent capitalization and spacing
- Category names that don't match
- Numbers stored as text, and prices with $ signs
- Negative quantities
- Store ids written different ways across files
- Weather data in a different timezone than the sales data

Data cleaning decision logging

Weather API and join
- API call with retries
- Parsing it into a DataFrame
- Timezone alignment
- Checked join to sales

Analysis
- Create at least 6 plots
- Find correlations and relationships

Presentation

Add a README.md file

From this project, Emma will learn more about data cleaning and decision logging. Raffaella will learn more about APIs and joins. Kylie will hone her analysis and write-up skills. Miriam will learn more about how to make effective charts that inform people on the data. These are all skills that we wanted to learn more about and get better at. Overall, all of us will learn how to be good teammates and collaborators.

What limits our time is our outside academic responsibilities and work. Within the next couple of weeks, all of us have upcoming midterms. However, we will ensure that we dedicate time outside of class individually and as a group to work on the project. Every week, we will set personal tasks of what we are completing to ensure that we meet the deadlines and are not procrastinating the work in the end.

What we want to avoid is procrastinating the work at the end and not communicating with each other. If we follow the rules that we outlined in the "How You Work Together" section below, then we this will ideally not be an issue.

### How We Work Together
- We will all come to every class.
- We will communicate via the group chat that we created the first day of group work called "Walmart Midterm".
- We will assign tasks and update each other on changes made/questions we have/future work. If specific questions are asked of a group member, they are expected to acknowledge the message within 24 hours. 
- We will meet at least once a week outside of class time on Wednesdays at 10am. If we need more time outside of class to work, we will schedule to meet Fridays during the normal class time from 9:00-9:50am.
- If we disagree on the direction of our project, we will look at the data first to try to resolve the conflict. If we still disagree and need an ultimate decision maker, the owner of that part decides. All decisions (especially ones that we made after a disagreement) will be logged in our notebook.
- If someone is not being a responsive and responsible group member, we will bring it to light as soon as we figure it out to not delay the progress of our work. We will all make sure to hold each other accountable. For instance, if someone is taking more than 24 hours to respond to a directed question in the group chat, we will check in with the person by calling or when we see them the next class in a polite manner. If the person is still not responsive after 48 hours, we will have a group meeting to re-evaluate and check in. If this issue is still not resolved, we will email Professor Williamson.
